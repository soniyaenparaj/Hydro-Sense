About HydroSense

Student project demonstration

HydroSense is a mobile-friendly prototype for illustrating water-quality monitoring workflows. It currently uses simulated turbidity, temperature and water-level readings. It is not connected to an ESP32, sensors, cloud database or external notification service. No pH parameter is included. Never use demo data to make health or drinking-water decisions.
