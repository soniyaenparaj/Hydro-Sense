HydroSense PWA deployment

1. Upload all files in this folder to a static HTTPS host such as GitHub Pages.
2. Keep the files together in the same directory.
3. Open the HTTPS URL on your phone.
4. iPhone: use Safari > Share > Add to Home Screen.
5. Android: use Chrome > menu > Install app or Add to Home screen.

Important: sensor readings, status indicators, and alerts remain a front-end simulation. They are not connected to real ESP32 hardware or a cloud service.
